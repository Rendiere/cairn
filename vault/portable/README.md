# Brain

{{owner}}'s portable vault: what {{owner}} understands about tools, formats and ideas that would stay true
at any employer. Notes are written only through the cairn plugin (`/cairn:study`, `/cairn:interview`,
`/cairn:sweep`), which holds the rules.

When {{owner}} has an employer, a company vault nests this one at `general/`. Notes here never link to
company notes or name anything from an employer, and a pre-commit hook rejects the employer's terms.

## Layout

- `concepts/`, `synthesis/`: notes, one per topic, kebab-case filenames
- `queue/`: open questions, one file each
- `study/<topic>/`: study packs, reading material and never notes
- `labs/<lab>/`: runnable environments on mock data
- `templates/`: one per note type
- `cairn.toml`: owner and review cadence

With no company vault this vault also holds `systems/`, `projects/`, `people/` and `interviews/`.
