# Brain

{{owner}}'s vault: what {{owner}} understands, written in their own words. Notes are written only through
the cairn plugin (`/cairn:study`, `/cairn:interview`, `/cairn:sweep`), which holds the rules.

Notes about an employer's systems, projects and people carry `company: <employer>` in their frontmatter.
General notes never link to them, so one employer's notes can be kept or deleted as a set.

## Layout

- `concepts/`, `systems/`, `projects/`, `synthesis/`, `people/`: notes, one per topic, kebab-case filenames
- `maps/`: index pages for company notes; plain items are notes not written yet, links are notes that exist
- `interviews/`: dated interview transcripts and sweep records
- `queue/`: open questions, one file each
- `study/<topic>/`: study packs, reading material and never notes
- `labs/<lab>/`: runnable environments on mock data
- `templates/`: one per note type
- `cairn.toml`: owner, current employer and review cadence
